bevel.css v0.1.0 reference

Bootstrap 2.0’s look for every app on hearth, in one plain stylesheet built only on CSS that has worked in every major browser for at least 30 months.

One file

Copy the release file into your app’s static folder and link it before your own stylesheet. No build step, no web fonts, no images, no JavaScript.

Your CSS wins

Everything sits in @layer bevel.*. Write your app’s CSS outside any layer and it overrides the library without !important.

Accessible markup is styled markup

States take the class or the ARIA form: .active or aria-current, .disabled or aria-disabled, .error or aria-invalid.

<link rel="stylesheet" href="/static/bevel-0.1.0.css">

Body text

The lead paragraph: 20px on a 27px line, for the one sentence that sets up a page.

Body text is 13px on an 18px line. It carries links, strong words, small text that keeps the surrounding size and inline code such as hearth deploy recipes.

A longer paragraph wraps the way you’d expect. Each app keeps a small manifest next to its code, and hearth reads it to decide how to pull, build and run the app, which port it listens on, and whether it should come back after the machine restarts. Everything else has a sensible default, so most manifests are four or five lines long.

Layout A container, rows and sections

The .container centers content at 724px, 940px or 1170px, and is fluid below 768px. Each .section starts 60px below the one before; the first sits 18px below the navbar. A .page-header opens each section.

    <div class="page-header"><h1>Apps <small>Five apps on hearth-01</small></h1></div>

Navbar The dark top bar

Links on the left, the brand on the right. Mark the current page with aria-current="page" (as in the bar at the top of this page) or .active (below). Below 768px the links wrap onto more rows and the divider hides.

Add .navbar-sticky to keep the bar at the top while the page scrolls under it, as the bar on this page does. Below 768px it scrolls away with the page.

Buttons Default, primary and danger

Variants

Blue is the one action you most expect someone to take; red is the one they can’t undo.

Elements

.btn works the same on <button>, <a> and <input type="submit">.

Link Primary link

Sizes

With an icon

Pressed

Pressed buttons lose their gradient and sink. Use .active, or aria-pressed="true" on a toggle.

Disabled

Use the disabled attribute on buttons and inputs. Links can’t be disabled natively, so give them .disabled together with aria-disabled="true" and no href.

Alerts Feedback in four tints

Use role="alert" for errors that need attention now and role="status" for everything else.

Disk: over 60% full. This is the default warning alert.
Failed. eink-sync exited with status 1.
Deployed. chess-trainer v0.9.2 went live 2 hours ago.
Heads up! notebook is deploying.

eink-sync stopped responding

It exited with status 1 three days ago and hasn’t restarted.

The last log line says it couldn’t open its frame buffer, which usually means the state folder was cleaned up while the app was running. Restoring the folder from last night’s backup and retrying is safe.

Backups are running late

The nightly backup took 41 minutes, up from 6. Something large may have landed in a data folder.

Hero unit One big callout

Add .hero-unit when a page needs a large callout, such as an app’s home page; leave it out and nothing changes. The heading is 60px from 768px up and 36px below it. Paragraphs inside are 18px on a 27px line.

Utilities A handful, no more

.muted sets text in the muted grey, for asides and timestamps. Use it on white only.

.text-right aligns to the end of the line, for numbers and trailing actions.

.table-scroll wraps a wide table; see Tables.
